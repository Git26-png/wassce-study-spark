# WASSCE Prep Hub

A mobile-friendly educational web app for students practising WASSCE subjects.

Live site: https://marvelous-queijadas-b6ce78.netlify.app/

## Tech stack

- React
- TypeScript
- TanStack Start
- Tailwind CSS
- TanStack Router

## Features

- Core Mathematics, Integrated Science, English Language and Social Studies quizzes
- Timed and practice modes
- Immediate answer feedback and explanations
- Score review and missed-question review
- Light and dark themes
- Local, on-device saving of theme preferences and high scores
- Study strategy articles
- About, privacy and contact pages

## Development

```sh
npm install
npm run dev
```

## Validation

```sh
npm test
npm run lint
npm run build
```
