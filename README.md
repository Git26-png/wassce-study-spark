# WASSCE Prep Hub

A free, mobile-friendly WASSCE practice quiz and study guide built with React, TypeScript, TanStack Start and Tailwind CSS.

## Features

- Practice quizzes for Core Mathematics, Integrated Science, English Language and Social Studies
- Timed and untimed modes
- Instant answer explanations and score review
- WASSCE study strategy articles
- About, privacy and contact information

## Development

```sh
npm install
npm run dev
```

## Validation

```sh
npm test
npm run lint
npm run build
```

## Deployment

This app can be deployed on Netlify or another HTTPS hosting provider. Before applying for Google AdSense:

1. Publish it on a custom domain you control.
2. Replace `public/ads.txt` placeholder comments with the exact verified `ads.txt` line from your AdSense account.
3. Submit the domain in Google Search Console and verify sitemap discoverability.
4. Ensure the privacy, about and contact pages are live and accurate.

AdSense approval depends on Google policies, domain ownership, original content, traffic and review. This repository cannot guarantee approval or payout.
